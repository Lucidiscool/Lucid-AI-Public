HOSTING

Lucid runs on your computer

The computer running the host does the AI work. Keep it awake and connected while visitors use Lucid or while you use the Admin dashboard. The model does not run on a hosted AI service.

Start or install the host on Windows

Download the Windows installer from the private Lucid AI Admin Host repository while signed into GitHub, then follow its README. If Lucid is already installed, open its folder and run:

start-local-host.cmd

Enter your admin passcode when prompted. Keep the terminal open. To stop sharing, run stop-public.cmd or press Ctrl+C.

Start or install the host on Linux

Download the Linux installer from the private Lucid AI Admin Host repository while signed into GitHub, then follow its README. After installing the local model runtime and setting up GitHub access, start Lucid from its folder:

./start-local-host.sh

Enter your admin passcode when prompted. Keep the terminal open. To stop sharing, press Ctrl+C. Linux needs a Linux-compatible llama.cpp build and a local_model.json configuration for the model you installed.

If this page says the host is offline, start the host and reload Admin after the website finishes updating.
